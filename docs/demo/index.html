Method, assumptions and limits

What is recorded

These are saved calls to the actual Python evaluate_sweep(training, validation), using original simulated single-point scattering and exact antenna geometry. The optional generator truth is separate context and was never supplied to inference.

What a passing result means

Stable hardware response and known receiver positions are trusted inputs. Passing a held-position test does not establish those assumptions. The search is finite: neither exhaustive solution coverage nor global uniqueness is established.

What this viewer can do

Camera, receiver position, retained mode and signal selection change the view of frozen data. This page does not fit new inputs. Use the full local workshop for editing and recomputation.

What remains untested

No hardware sensing, device precision or room reconstruction is established by these simulations. Small distances from synthetic truth are not measured device accuracy.
